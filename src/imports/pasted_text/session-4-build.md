# BUILD SESSION 4 — WHAT I TRIED

Session 4 takes place after the participant has completed the experiments designed in Session 3.

The purpose of Session 4 is to help participants reflect on their real-world experiments, identify patterns, decide what they want to continue, and create a practical 90-day roadmap.

The participant performs all activities.

The facilitator guides the discussion, observes participant progress in real time, assists when required, and reviews the completed journey.

All actions must be saved automatically.

All participant and facilitator actions must synchronize in real time.

Session 4 should be built as a **collaborative Miro-style workshop board**, consistent with Sessions 1 and 3. Do not build traditional forms or questionnaires.

---

# SESSION FLOW

## STEP 1 — WHAT I TRIED

### Prompt

**"Over the past week, what did you actually do?"**

Create a large open collaborative board.

Place a decorative tree illustration in the center of the workspace (similar to the Miro board).

Display a **Sticky Note Stack** on the right side.

The board should initially be empty.

### Participant Actions

* Create unlimited sticky notes.
* Write down everything they actually tried after Session 3.
* Edit sticky notes.
* Delete sticky notes.
* Drag sticky notes anywhere on the board.
* Rearrange sticky notes freely.

Examples are only for facilitator understanding and should **NOT** appear as preloaded content.

### Facilitator Actions

* Observe participant work in real time.
* Add sticky notes.
* Edit participant sticky notes.
* Delete sticky notes.
* Move sticky notes.
* Guide discussion.

### Data Saved

* Sticky note text
* Sticky note position
* Creation timestamp
* Last edited timestamp
